# Swift Practice Tasks

Add your completed solutions to this folder as separate `.swift` files.

## Fundamentals
- [ ] Create variables and constants for a student profile.
- [ ] Calculate total, average, and percentage from subject marks.
- [ ] Check eligibility using comparison and logical operators.
- [ ] Convert Celsius to Fahrenheit.

## Collections
- [ ] Find the largest and smallest values in an array.
- [ ] Remove duplicates from an array using a Set.
- [ ] Count word frequency using a dictionary.
- [ ] Sort trainee names alphabetically.

## Enumerations, structures, and classes
- [ ] Create an order-status enum and use switch.
- [ ] Create a student structure and calculate average marks.
- [ ] Create a bank-account class with deposit and withdrawal.
- [ ] Demonstrate value-type and reference-type behavior.

## Optionals and ARC
- [ ] Safely parse a string into an integer.
- [ ] Write a function that accepts an optional string.
- [ ] Use optional chaining on a nested property.
- [ ] Explain how strong references can cause a retain cycle.

## Functions and closures
- [ ] Check whether a number is prime.
- [ ] Check whether a string is a palindrome.
- [ ] Use filter to select even numbers.
- [ ] Use map to convert names to uppercase.

## Protocols, generics, and errors
- [ ] Create a payment-method protocol.
- [ ] Extend String with a validation property.
- [ ] Write a generic function to swap two values.
- [ ] Throw a custom error for invalid input.

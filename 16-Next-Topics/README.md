# Intermediate Swift and SwiftUI Checklist

This is a suggested next learning sequence. Follow the order used by your trainer and update the checklist only after practicing each topic.

## Swift intermediate
- [ ] Tuples and type aliases
- [ ] Stored and computed properties
- [ ] Property observers: willSet and didSet
- [ ] Access control: private, fileprivate, internal, public, and open
- [ ] Class inheritance and method overriding
- [ ] Protocol delegation

## SwiftUI introduction
- [ ] Create an iOS App project in Xcode
- [ ] Understand View and body
- [ ] Build layouts with VStack, HStack, and ZStack
- [ ] Use Text, Image, and Button
- [ ] Manage local state with @State
- [ ] Read input using TextField
- [ ] Display data with List and ForEach
- [ ] Navigate using NavigationStack and NavigationLink

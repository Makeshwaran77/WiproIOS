# Wipro iOS Training

A record of my Wipro iOS development training, including Swift fundamentals, practice programs, and daily learning notes.

## Topics covered

1. Development environment: macOS, Xcode, Command Line Tools, and iOS Simulator
2. Swift introduction, features, syntax, variables, and constants
3. Operators and expressions
4. Collections: arrays, sets, and dictionaries
5. Enumerations, structures, and classes
6. Optionals and optional handling
7. Automatic Reference Counting (ARC) and memory management
8. Functions, parameters, and return types
9. Closures and higher-order functions
10. Protocols and extensions
11. Generics and error handling

## Repository structure

- `01-Swift-Fundamentals/`: variables, constants, types, and operators
- `02-Collections/`: arrays, sets, and dictionaries
- `03-Enums-Structs-Classes/`: value types, reference types, and enums
- `04-Optionals-ARC/`: safe optional handling and memory management
- `05-Functions-Closures/`: functions, closures, and higher-order functions
- `06-Protocols-Generics-Errors/`: protocols, extensions, generics, and errors
- `07-Daily-Learning-Log/`: daily summaries and practice checklist
- `08-Practice-Tasks/`: suggested hands-on exercises

## Running the examples

Open a `.swift` file in Xcode, or run it using the Swift toolchain from Terminal:

```bash
swift path/to/File.swift
```

Some environment setup tasks require macOS and Xcode and cannot be demonstrated by a standalone Swift source file.

## Daily workflow

1. Create or update the file for the topic practiced that day.
2. Run the program and verify its output.
3. Add a short note to `07-Daily-Learning-Log/README.md`.
4. Commit with a descriptive message:

```bash
git add .
git commit -m "Add Swift collections practice"
git push origin main
```

> These are learning examples and suggested exercises. Update the daily log to reflect the work actually completed in each session.

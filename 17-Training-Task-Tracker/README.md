# Training Task Tracker — SwiftUI Mini Project

A small practice app that applies Swift structures, arrays, functions, closures, and SwiftUI state.

## Features
- Display a list of training topics.
- Add a topic using a text field.
- Mark a topic as completed.
- Display completed and total task counts.
- Delete a topic from the list.

## How to run
1. Open Xcode on macOS.
2. Create an iOS App project using SwiftUI.
3. Add `TrainingTask.swift` and `TrainingTaskTrackerView.swift` to the project.
4. Set `TrainingTaskTrackerView()` as the root view in the app entry point.
5. Run using an iOS Simulator.

This folder contains view/model source files, not a complete Xcode project bundle.

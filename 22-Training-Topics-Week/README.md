# Networking and UIKit Training Checklist

Use this checklist to track the five topics from the next training block. Mark an item complete only after attending, practicing, and understanding it.

## Topic 1 — JSON Parsing and Decoding API Responses
- [ ] Understand JSON objects and arrays.
- [ ] Create Swift models conforming to Decodable or Codable.
- [ ] Decode JSON using JSONDecoder.
- [ ] Handle missing or mismatched fields and decoding errors.
- [ ] Practice decoding a JSON object and JSON array.

## Topic 2 — Networking and JSON in application UI
- [ ] Understand URL, URLRequest, and URLSession.
- [ ] Make an asynchronous GET request.
- [ ] Validate HTTP status codes.
- [ ] Decode the response into Swift models.
- [ ] Show loading, success, empty, and error states in the UI.
- [ ] Update UIKit UI on the main thread.

## Topic 3 — UIKit fundamentals
- [ ] Understand UIView and UIViewController.
- [ ] Build a view hierarchy using addSubview.
- [ ] Learn viewDidLoad and viewWillAppear.
- [ ] Add controls and handle user interactions.

## Topic 4 — Storyboards and Auto Layout
- [ ] Create screens in Interface Builder.
- [ ] Connect IBOutlet and IBAction.
- [ ] Add constraints using the safe area.
- [ ] Test different simulator sizes and orientations.

## Topic 5 — UIKit controls, UIStackView, and modal presentation
- [ ] Practice UILabel, UIButton, UITextField, and UIImageView.
- [ ] Arrange controls using UIStackView.
- [ ] Present a view controller modally.
- [ ] Dismiss a presented view controller.

# SwiftUI Basics

SwiftUI is Apple's declarative framework for building user interfaces across Apple platforms. These examples are intended for an Xcode project that includes SwiftUI. They are not standalone command-line programs.

## Create a SwiftUI project

1. Open Xcode on macOS.
2. Select **File → New → Project**.
3. Choose **iOS → App**.
4. Select **SwiftUI** as the interface.
5. Choose Swift as the language.
6. Run the project using an iOS Simulator.

## Example files

- `01_HelloSwiftUI.swift`: basic view and layout
- `02_StateAndButton.swift`: state and button interaction
- `03_TextFieldAndForm.swift`: text input and form layout
- `04_ListAndForEach.swift`: dynamic lists
- `05_NavigationStack.swift`: navigation between screens

Place each example in a SwiftUI app project and use the shown view as the app's root view or as a separate view file.
